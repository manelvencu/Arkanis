# Las Tierras de Arkanis

Videojuego 2D de aventura desarrollado con Phaser, TypeScript y Vite.

## Estado

El proyecto se encuentra en desarrollo activo.

Flujo jugable actual:

`Intro -> Selección de personaje -> Zona de Entrenamiento -> Mapa del Mundo -> La Aldea`

La Aldea dispone actualmente de navegación por grid, NPC, tres cabañas jugables e iglesia.

El siguiente bloque previsto es la transición desde La Aldea hacia **Las Tierras del Fuego** mediante el mapa del mundo.
