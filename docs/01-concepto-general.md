# Las Tierras de Arkanis

## Concepto general

**Las Tierras de Arkanis** será un videojuego 2D de aventura con vista cenital clásica, inspirado en la sensación de exploración de los Zelda clásicos, pero con identidad, personajes, mundo, historia y recursos visuales propios.

El proyecto se desarrollará de forma incremental a partir de las ideas que vayan surgiendo durante el proceso.

## Tecnología prevista

- Phaser
- TypeScript
- Vite
- GitHub
- GitHub Pages
- Guardado local en navegador durante las primeras fases

## Principios de desarrollo

- Desarrollo por iteraciones pequeñas y jugables.
- Prioridad a que cada nueva idea pueda probarse pronto en el juego.
- El proyecto se documentará en archivos Markdown dentro de `/docs`.
- Los personajes jugables compartirán las mismas capacidades y controles; las diferencias serán visuales y de nombre.

## Vista del juego

- Vista cenital clásica.
- Cámara siguiendo al personaje.
- Movimiento inicial en cuatro direcciones: arriba, abajo, izquierda y derecha.
