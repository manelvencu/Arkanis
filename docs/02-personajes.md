# Personajes jugables

El juego tendrá inicialmente cuatro personajes seleccionables. Todos compartirán las mismas capacidades, velocidad, controles y sistema de combate. Las diferencias serán únicamente visuales y de nombre.

## Tiana

- Caucásica.
- Pelo rubio.
- Dos trenzas largas.
- Ojos verdes.
- Camiseta lila.
- Pantalón corto de jean azul.
- Zapatos negros con cordones rosas.
- Pulsera azul claro.

## Lupe

- Caucásica.
- Pelo marrón.
- Coleta alta.
- Ojos marrones.
- Camiseta azul.
- Pantalón corto verde.
- Zapatos lilas.
- Collar dorado con una ola de mar.

## Manel

- Caucásico.
- Muy poco pelo.
- Camiseta negra.
- Pantalón corto gris.
- Zapatos marrones.

## Cintia

- Caucásica.
- Pelo rubio.
- Coleta alta.
- Ojos marrones.
- Camiseta verde.
- Pantalones cortos grises.
- Zapatos marrones.
- Pulsera con una esmeralda verde.

## Selección de personaje

Antes de comenzar una nueva partida habrá un menú de selección entre los cuatro personajes. La elección se mantendrá durante la partida.
