# Identidad visual y controles táctiles

## Título del juego

El título **Las Tierras de Arkanis** tendrá una estética de saga mágica y fantástica, con inspiración general en títulos de fantasía gótica.

Criterios visuales acordados:

- `LAS TIERRAS DE` aparecerá como encabezado secundario.
- `ARKANIS` será el elemento principal del logotipo.
- Tipografía serif de fantasía, con remates marcados.
- Color dorado envejecido.
- Contorno oscuro grueso.
- Sombra y sensación de relieve.
- Se busca una identidad propia; no se copiará literalmente ningún logotipo comercial existente.

## Compatibilidad táctil

El selector de personaje ya puede utilizarse mediante toque en pantalla porque las tarjetas son elementos interactivos de Phaser.

En el estado actual del prototipo:

- Selección de personaje: compatible con ratón y pantalla táctil.
- Movimiento: teclado mediante flechas.
- Rayo mágico: barra espaciadora.

## Evolución prevista para tablet

Para poder jugar completamente desde una tablet se añadirá:

- Cruceta virtual táctil para arriba, abajo, izquierda y derecha.
- Botón táctil independiente para lanzar el rayo mágico.
- Los controles de teclado seguirán disponibles simultáneamente en PC.
- Los controles táctiles se mostrarán únicamente cuando corresponda o cuando el dispositivo use interacción táctil.
